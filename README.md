# pAIr-front
AI 활용 역량 진단 플랫폼 프런트 (React, TypeScript, Vite). 백엔드는 [pAIr-back](https://github.com/KosAmigo/pAIr-back).

## 실행
- 프런트: `npm --prefix frontend install` 후 `npm --prefix frontend run dev` (포트 5173, API는 백엔드 8180으로 프록시)
- 카메라 감독: `npm --prefix cam-proctor run dev`
- 화면 규칙은 `DESIGN.md`, 기획·ERD·평가 문서는 pAIr-back 의 `docs/`

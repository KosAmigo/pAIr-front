# 채점 툴 공유 폴더

메인 화면 오른쪽 위 아이콘(채점 툴)에서 쓰는 파일입니다. 이 폴더는 git으로 팀원과 공유합니다.

## versions/ : 채점 프롬프트 버전

- 버전 하나가 JSON 파일 하나입니다. 공통 채점 규칙, R1 비교 프롬프트, 체크별 판정 기준이 들어 있습니다(배점은 기록용이고 채점에는 기준표의 고정 배점을 씁니다).
- `v1_기본.json`은 코드에 있던 프롬프트로 서버가 처음 켜질 때 자동으로 만듭니다.
- 채점 툴에서 [이 버전을 고쳐 새로 만들기]로 저장하면 `날짜-시각_작성자_이름.json` 파일이 생깁니다. 여러 명이 동시에 만들어도 이름이 겹치지 않습니다.
- 한 번 저장한 버전은 고치지 않습니다. 바꾸고 싶으면 새 버전으로 저장합니다. 지난 실험 결과가 어느 프롬프트로 나왔는지 헷갈리지 않게 하려는 것입니다.
- 공유: 새 버전 파일을 커밋하고 push하면, 팀원이 pull받았을 때 버전 목록에 뜹니다.
- 체크 항목 구성과 배점은 고정입니다. 툴에서는 공통 채점 규칙, R1 비교 프롬프트, 체크별 판정 기준 문장만 바꿀 수 있습니다.

## samples/ : 샘플 응시

- 팀원 모두가 같은 응시로 비교할 수 있게 넣어 둔 가상 응시 7개입니다. 목록과 설명은 `samples/index.json`에 있습니다.
- 정답에 가까운 코드가 들어 있으므로 응시자가 이 저장소를 볼 수 없게 private으로 유지합니다.

## 각자 PC에만 있는 것 (git에 올라가지 않음)

- 실제 응시 채점에 쓸 버전: `pilot-data/grader/active.txt` (툴의 [실제 채점에 사용])
- 실험 채점 결과: `grader/runs/` (git으로 팀원과 공유. 커밋, push 하면 팀원의 채점 툴 결과 탭에도 보임. 배치 채점이면 배치 ID와 받은 결과가 `batch.json`에 있어, 서버를 다시 켜면 이어서 받음) (툴의 [결과 파일 내보내기]로 JSON 하나로 받아 공유할 수 있음)
- API 키: 각자 환경 변수 `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`. 실험 채점 비용도 각자의 키로 나갑니다.

# 채점 툴 공유 폴더

메인 화면 오른쪽 위 아이콘(채점 툴)에서 쓰는 파일입니다. 이 폴더는 git으로 팀원과 공유하고, 팀 전체가 같은 설정을 씁니다(작성자 구분 없음).

## versions/ : 채점 프롬프트 버전

- 버전 하나가 JSON 파일 하나입니다. 공통 채점 규칙과 체크별 판정 기준이 들어 있습니다(배점은 기록용이고 채점에는 기준표의 고정 배점을 씁니다).
- `v2_기본.json`은 6개 역량 기준의 코드 기본값으로, 서버가 처음 켜질 때 자동으로 만듭니다. `v1_기본.json`은 예전 5개 항목 기준입니다.
- 채점 툴에서 [이 버전을 고쳐 새로 만들기]로 저장하면 `날짜-시각_이름.json` 파일이 생깁니다. 같은 이름이 있으면 뒤에 `-2`, `-3`이 붙습니다.
- 한 번 저장한 버전은 고치지 않습니다. 바꾸고 싶으면 새 버전으로 저장합니다. 지난 실험 결과가 어느 프롬프트로 나왔는지 헷갈리지 않게 하려는 것입니다.
- 체크 항목 구성과 배점은 고정입니다. 툴에서는 공통 채점 규칙과 체크별 판정 기준 문장만 바꿀 수 있습니다.

## active.txt : 실제 응시 채점에 쓸 버전

- 툴의 [실제 채점에 사용]을 누르면 이 파일에 버전 ID가 저장됩니다. 파일이 없으면 `v2_기본`을 씁니다.
- 커밋하고 push하면 팀 전체의 실제 채점 버전이 같아집니다.

## runs/ : 실험 채점 결과

- 실험 한 번이 폴더 하나입니다. 커밋하고 push하면 팀원의 채점 툴 결과 탭에도 보입니다.
- 배치 채점이면 배치 ID와 받은 결과가 `batch.json`에 있어, 서버를 다시 켜면 이어서 받습니다.
- "내 응시"로 실험하면 그 응시의 대화 내용도 결과 파일에 들어가니, 올리기 전에 확인하세요.

## samples/ : 샘플 응시

- 팀원 모두가 같은 응시로 비교할 수 있게 넣어 둔 가상 응시 7개입니다. 목록과 설명은 `samples/index.json`에 있습니다.
- 정답에 가까운 코드가 들어 있으므로 응시자가 이 저장소를 볼 수 없게 private으로 유지합니다.

## 각자 PC에만 있는 것

- API 키: 각자 환경 변수 `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`. 실험 채점 비용도 각자의 키로 나갑니다.

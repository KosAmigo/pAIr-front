# pAIr 요구사항 정의서

- 근거: ERD v2 DDL(eXERD 내보내기, PostgreSQL)
- 우선순위: 상(필수) / 중(중요) / 하(선택)
- 구분: 기능(FR) / 비기능(NFR) / 데이터 제약(DR)

## 1. 시스템 개요
pAIr는 응시자가 AI 어시스턴트와 함께 실무형 과제(DEV/BIZ)를 수행하고, 그 과정(대화·파일·작업 기록)과 결과(문항 답변)를 LLM 판정 모델로 채점하는 역량 평가 서비스이다. 개인은 자가진단(SELF)으로, 기업은 감독이 붙은 실전 회차(LIVE)로 이용한다.

### 사용자 구분
| 구분 | 설명 |
|---|---|
| 일반 회원(USER) | 과제를 자가진단으로 응시하고 결과를 확인 |
| 기업 담당자(COMPANY) | 소속 회사의 실전 회차를 열고 응시자를 초대·관리 |
| 관리자(ADMIN) | 과제·문항·루브릭·채점 프롬프트 관리 |
| 초대 응시자 | 메일 링크로 실전 회차에 입장 |

## 4. 데이터 무결성 요구사항
| ID | 내용 |
|---|---|
| DR-01 | COMPANY 권한 회원은 company_id가 NULL일 수 없다. |
| DR-02 | 과제 자료(TASK_FILE) 첨부는 task_file_id가 있어야 한다. |
| DR-03 | 글 답변은 SHORT/ESSAY, 객관식 답변은 SINGLE/MULTI 문항에만 연결된다(문항 ID+유형 복합 FK). |
| DR-04 | 선택한 보기는 해당 문항의 보기여야 한다(보기 ID+문항 ID 복합 FK). |

| DR-06 | 감독 이벤트의 지속 시간은 0 이상, 확신도는 0~1이다. |

## 5. DDL 검토 중 발견한 문제 (확정 전 수정 필요)
| # | 위치 | 문제 | 제안 |
|---|---|---|---|
| 1 | companies | `COL` 컬럼에 데이터 타입이 없다(상태: 가입대기/승인). | `status varchar(20) NOT NULL DEFAULT 'PENDING'` |
